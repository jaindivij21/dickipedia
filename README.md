# dickipedia

Open-source accountability hub for India's elected Lok Sabha MPs (18th Lok Sabha, 2024). Every figure is sourced from a **public record about a public official's public conduct** — the site reports facts and routes citizens to lawful channels; it authors no accusations.

> Coverage grows over time as records are verified and contributors pitch in.

## Licences

- **Aggregated dataset:** ODbL-1.0.
- **Photos:** each under its own licence.
- **Code:** MIT. **Community content** (edits / discussion): separate contributor terms.

See [`ATTRIBUTIONS.md`](./ATTRIBUTIONS.md) and [`CONTRIBUTING.md`](./CONTRIBUTING.md).

**Legal stance:** public officials only; public records + arithmetic; no platform-authored accusations; criminal data shown "as self-declared (pending ≠ convicted)"; electoral-bond funding shown party-level, never per MP.
